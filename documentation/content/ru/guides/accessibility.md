# Доступность

Компоненты содержат базовые ARIA-роли и клавиатурное управление, но приложение
остаётся ответственным за понятные подписи, контраст и корректный порядок
фокуса страницы.

## Обязательные подписи

- передавайте конкретный `label` в `KSelect`, `KActionMenu` и табличные фильтры;
- задавайте `caption` для `KDataTable`, даже если он визуально скрыт;
- используйте `selectRowLabel`, если номер строки недостаточно информативен;
- передавайте осмысленные `tableLabel` и `cardsLabel` для переключателя вида;
- `logoAlt` должен быть пустым для декоративного логотипа или описательным,
  если логотип несёт смысл.

## Клавиатурные сценарии

| Компонент | Клавиши |
| --- | --- |
| `KSelect` | Enter/Space открывают, стрелки выбирают, Escape закрывает |
| `KTabs` | Left/Right, Home, End |
| `KColumnPicker` | Escape; в reorder mode — Up/Down |
| `KActionMenu` | Up/Down и Escape |
| `KModal` | Escape и циклический Tab внутри панели |
| Resize таблицы | Left/Right на separator |

## Focus и Teleport

Select, column picker, action menu и modal используют `Teleport to="body"`.
Не скрывайте `body` через `aria-hidden`, пока открыт такой слой. Проверяйте, что
проектные z-index и transform не перекрывают панели.

После выбора или Escape focus возвращается на trigger там, где это необходимо.
После закрытия modal восстанавливается элемент, активный до открытия.

## Проверка приложения

1. Пройти сценарий только клавиатурой.
2. Проверить видимый focus в светлой и тёмной темах.
3. Проверить подписи в accessibility tree.
4. Проверить zoom 200% и узкий viewport.
5. Убедиться, что loading и empty state озвучиваются корректно.
