# Kokhanenko UI

По умолчанию отвечай на русском языке.

Это универсальная Vue 3 UI-библиотека. Она не должна зависеть от API,
маршрутов, состояния или предметной области конкретного приложения.

## Инварианты

- Vue находится в `peerDependencies` и не включается в итоговый bundle.
- Компоненты и их стили подключаются раздельными entry points.
- Общие токены и opt-in base styles не импортируются компонентами скрыто.
- Компонент не должен тянуть код или CSS несвязанных компонентов.
- Библиотека содержит нейтральные светлые/тёмные значения и контракт семантических токенов.
- Универсальный CSS-контракт `data-kui-scheme="light|dark|system"` принадлежит библиотеке.
- Брендовые палитры, видимый переключатель и сохранение выбора принадлежат приложению-потребителю.
- Предметно-специфичные виджеты не входят в базовый пакет.
- Новая предметная коллекция оформляется отдельным subpath/package layer.
- Перед изменениями запускай `npm test`, `npm run typecheck` и `npm run build`.

## Структура

- `src/foundation` — семантические токены и opt-in base styles.
- `src/controls` — атомарные интерактивные контролы.
- `src/feedback` — сообщения и подсказки.
- `src/overlays` — модальные и всплывающие слои.
- `src/shell` — конфигурируемая оболочка приложения.
- `src/composables` — переиспользуемое поведение без UI.
