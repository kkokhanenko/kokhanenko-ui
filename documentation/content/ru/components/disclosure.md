# KDisclosure

`KDisclosure` показывает второстепенное или подробное содержимое по запросу
пользователя. В основе находятся нативные `details` и `summary`, поэтому
раскрытие работает мышью, клавиатурой и со средствами доступности.

```javascript
import { ref } from 'vue';
import { KDisclosure } from '@kokhanenko/ui/disclosure';

const open = ref(false);
```

```xml
<KDisclosure
  v-model="open"
  title="Текст промта"
  description="Инструкция модели"
>
  <pre>{{ prompt }}</pre>
</KDisclosure>
```

## Props

| Prop | Тип | По умолчанию |
| --- | --- | --- |
| `modelValue` | `boolean` | обязательный |
| `title` | `string` | обязательный |
| `description` | `string` | отсутствует |

Компонент создаётся как controlled UI: приложение хранит состояние и принимает
`update:modelValue`. Событие `toggle` дополнительно сообщает фактическое новое
состояние нативного элемента.

## Slots

| Slot | Назначение |
| --- | --- |
| `default` | Раскрываемое содержимое |
| `title` | Пользовательская разметка заголовка вместо `title` |
| `description` | Пользовательская разметка правого описания |

## Когда использовать

- для технических деталей, настроек и длинных пояснений;
- для прогрессивного раскрытия содержимого, которое не требуется постоянно;
- для группы независимых секций, когда разрешено открыть несколько сразу.

`KDisclosure` не управляет группой как взаимоисключающий аккордеон. Если по
сценарию одновременно должна быть открыта только одна секция, это состояние
координирует приложение.
