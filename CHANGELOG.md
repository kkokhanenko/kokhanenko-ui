# Changelog

## 0.1.0 — 2026-09-04

- Создана модульная Vue 3 UI-библиотека.
- Добавлены семантические токены с нейтральными значениями по умолчанию.
- Добавлены базовые контролы, feedback, overlays и конфигурируемый AppShell.
- Каждый компонент опубликован отдельной точкой импорта.
- AppShell получил заметную универсальную шапку рабочей области и раскрываемую вложенную навигацию с компактным flyout-режимом.
- Цвета оболочки вынесены в семантический контракт `--kui-shell-*`; брендовые темы и их переключение оставлены приложениям.
- В свёрнутой навигации восстановлены счётчик подразделов у иконки, точное центрирование и контур кнопки в соответствии с исходным паттерном.
- Добавлен CSS-only контракт схем `light`/`dark`/`system` на основе `color-scheme`, `light-dark()`, OKLCH и семантических токенов.
- Индикатор `KSelect` приведён к единому паттерну: стрелка всегда направлена вниз и не вращается при открытии.
- Исправлен первый замер Teleport-панелей: `bottom-end` больше не смещается влево при первом открытии по тексту контрола.
- `KTabs` больше не показывает ложную вертикальную прокрутку из-за однопиксельной нижней границы; горизонтальная прокрутка при реальном переполнении сохранена.
